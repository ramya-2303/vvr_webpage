# VVR WEBPAGE
This repository contains the frontend webpage developed as part of a mini project.  
The webpage is built using HTML, CSS, and JavaScript and is hosted live using -GitHub Pages.

This webpage serves as the frontend interface for the VVR mini project.  
It demonstrates basic web development concepts including page structure, styling, and client-side scripting.
